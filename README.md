# Tabuada Turbo

Jogo de tabuada de 1 a 10 para celular, de uso familiar. Funciona offline depois de instalado.

## Como instalar

1. Abra o endereço do jogo uma vez, com internet.
2. iPhone: no Safari, toque em Compartilhar e em "Adicionar à Tela de Início".
3. Android: no Chrome, abra o menu e toque em "Instalar app".

## Arquivos

- `index.html`: o jogo.
- `manifest.json`: nome e ícones do app.
- `sw.js`: guarda o jogo no aparelho para uso offline. Ao atualizar o jogo, troque o número da versão no início deste arquivo.
